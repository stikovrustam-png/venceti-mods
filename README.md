# Venceti Mods

Мод-инсталлер для GTA (CR / Launcher).

## Что делает

Устанавливает моды в игру одной кнопкой через Shizuku.

## Как пользоваться

1. Закинь свои моды в `/storage/emulated/0/Download/Venceti Mods/Files/`
2. Открой приложение
3. Выбери APK или Google Play версию игры
4. Нажми Start Mods
5. Появится кружок поверх экрана
6. Зайди в игру → тапни кружок → Download

## Куда копируется

- APK версия → `/Android/data/com.grand.cr/files/`
- Google Play версия → `/Android/data/com.grand.launcher/files/`

## Управление кружком

- Тап → открыть панель
- Перетаскивание → двигать
- Тап по ✕ → закрыть панель
- Удержание ✕ 3 сек → убить кружок
